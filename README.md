# Malayalam Conversational AI

A full-stack application for building a conversational AI interface optimized for the Malayalam language.

## Overview
This project comprises a frontend client and a robust backend designed for speech processing, conversational flow, and real-time interaction. It integrates various AI models and tools for seamless audio and natural language capabilities.

## Architecture
- **Frontend**: The user interface.
- **Backend**: Built with FastAPI, PyTorch, Pyannote Audio, SpeechRecognition, and OpenAI. Handles audio processing, speech-to-text, speaker diarization, and natural language understanding.

## Features
- Voice interaction and speech processing
- Speaker diarization (powered by pyannote.audio)
- Real-time API endpoints (FastAPI)
- Seamless integration with LLM models for natural language responses
